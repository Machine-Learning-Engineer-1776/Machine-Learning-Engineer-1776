# Hi, I'm Ron Lance 👋

ML/AI engineer building applied AI projects, from model notebooks to deployed web apps.

## Featured projects

- **[Pothole-Patrol](https://github.com/Machine-Learning-Engineer-1776/Pothole-Patrol)**: YOLOv8 pothole detector exported to ONNX, served in a Streamlit app with image upload, camera snapshots and a demo video ([pothole-patrol-ai.com](https://pothole-patrol-ai.com)).
- **[SmartFleet_Route_Optimizer](https://github.com/Machine-Learning-Engineer-1776/SmartFleet_Route_Optimizer)**: Streamlit prototype that fuses Chicago crime, taxi, traffic, weather and sensor data into route risk scores, plus Random Forest risk models and an X sentiment + LLM alert notebook.
- **[Brain_Suite_App](https://github.com/Machine-Learning-Engineer-1776/Brain_Suite_App)**: Streamlit app for brain MRI images; ResNet50 transfer-learning classifier (83.9% test accuracy, tumor vs. no tumor) plus a synthetic MRI viewer.
- **[CRISPR_Gene_Editing_GNN_Model](https://github.com/Machine-Learning-Engineer-1776/CRISPR_Gene_Editing_GNN_Model)**: Converts 34,582 CRISPR sgRNA sequences into graphs and trains GraphSAGE models with MLflow tracking (early-stage results).
- **[Synthetic_Image_Generation_Diffusion_Model](https://github.com/Machine-Learning-Engineer-1776/Synthetic_Image_Generation_Diffusion_Model)**: Synthetic brain MRI generation with a Stable Diffusion pipeline, compared against VAE, DCGAN, DDPM and U-Net GAN attempts.
- **[Fraud-Detection-in-Credit-Card-Transactions](https://github.com/Machine-Learning-Engineer-1776/Fraud-Detection-in-Credit-Card-Transactions)**: XGBoost vs. Logistic Regression + SMOTE on a highly imbalanced fraud dataset (XGBoost PR-AUC 0.88).
- **[Build-A-Me](https://github.com/Machine-Learning-Engineer-1776/Build-A-Me)**: Hackathon Streamlit app that chains YouCam AI API calls to build three full virtual makeovers from one selfie.
